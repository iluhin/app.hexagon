# Гексагон 1.1

Программа для Windows и обновление приложения для Android. Скачать:
**[hexagon.iluh.in/download](https://hexagon.iluh.in/download)** или файлы ниже.

## 🪟 Программа для Windows 1.0.0 — новая

Файл `hexagon-1.0.0.exe` — 7 МБ, установка не нужна: скачали и запустили.

- **Играет без интернета.** Партии с компьютером и вдвоём идут прямо на
  компьютере; онлайн, профиль и рейтинг — общие с сайтом и телефоном.
- **Своё окно** с тем же оформлением, тёмной и светлой темой, звуком и анимациями.
- **QR для телефона** внутри: «Игра на телефоне» внизу главного экрана.
- **Обновляется просто:** игра сама скажет о новой версии, файл скачает браузер.
- Нужна Windows 10 или 11 (встроенный компонент Edge WebView2).

> Файл пока не подписан сертификатом, поэтому при первом запуске Windows
> может показать синее окно SmartScreen: **«Подробнее» → «Выполнить в любом
> случае»**.

## 🤖 Android 1.0.1

Файл `hexagon-1.0.1.apk` встаёт поверх 1.0.0 — профиль и настройки сохранятся.

- **Игра сама сообщает о новой версии**: окно с номером, размером и списком
  изменений, кнопка «Обновить» отдаёт файл браузеру, «Напомнить завтра»
  откладывает на сутки. Если игру поставил магазин (RuStore и другие), окно
  не появляется — обновляет магазин.
- Плашка объявлений хорошо читается в светлой теме.
- Значок в окне итога — цвета ваших фишек; при поражении он приглушён.
- «Назад» со страницы загрузки возвращает к игре, а не закрывает приложение.

## 🌐 Сайт

- Страница загрузки показывает то, что нужно вашему устройству: QR на
  компьютере, кнопку на телефоне, шаги для iPhone, версию для Windows.
- Ссылки-приглашения в онлайн-стол из приложений ведут на сайт и открываются
  у друга сразу за столом.
