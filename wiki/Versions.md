# Версии

## 1.1 — 14 ноября 2026

- **Программа для Windows** 1.0.0: 7 МБ, без установки, играет без сети,
  своё окно с заголовком в стиле игры, размер под экран, обновления из игры.
- **Android 1.0.1**: игра сама сообщает о новой версии со списком изменений,
  плашка в светлой теме, значок итога цвета ваших фишек,
  «Назад» со страницы загрузки возвращает к игре.
- Страница загрузки: версия для Windows с подсказкой про SmartScreen.

## 1.0 — 14 ноября 2026

Первый полноценный выпуск.

- Новый интерфейс: тёмная и светлая темы, анимации клона, прыжка и захвата.
- Компьютер четырёх уровней считает ходы прямо на устройстве — отвечает сразу.
- Онлайн: быстрая игра, стол для друга по коду и ссылке, реванш.
- Профили, рейтинг Эло, статистика побед над каждым уровнем компьютера.
- Подсказки: сколько фишек даст ход, отмена хода, совет компьютера.
- Три поля: 37, 61 и 91 клетка.
- Установка на телефон как приложение.
- **Приложение для Android** 1.0.0: играет без сети, 0,4 МБ, три разрешения.
- Страница загрузки hexagon.iluh.in/download: QR-код на компьютере, кнопка на
  телефоне, инструкция для iPhone.
